# 図表を読む教材（#78）

既存の用語・概念問題に加え、7単元に14問の図表問題を追加した。描画とデータ表は同じ `CurriculumFigure` を使う。単位・区間・凡例は問題に答える前から確認できる。以下は教材用の架空データ。

| 単元 | 図表と与えられる値 | 読み取る量・正答 |
|---|---|---|
| 小4 `relations-data` | 気温16,20,24,22,18℃／時刻8,10,12,14,16時 | 8〜12時の上昇8℃ |
| 同上 | 学年×遊び、3年[12,8]人・4年[9,11]人 | なわとびの合計19人 |
| 小5 `rate-statistics` | 円グラフ、40人、割合40,30,20,10% | 水泳16人 |
| 同上 | 同じ割合の帯グラフ | 球技と陸上の合計50% |
| 小6 `ratio-data` | 0〜10,10〜20,20〜30,30〜40分の度数2,6,8,4人（以上〜未満） | 20分以上12人／10〜20分30% |
| 中1 `proportion-functions` | x=-2,-1,0,1,2／y=-6,-3,0,3,6 | x=2のyは6／比例定数3 |
| 中2 `linear-functions` | x=0,1,2,3,4／y=1,3,5,7,9 | 切片1／x=1〜3でyの増加量4 |
| 中2 `probability-distribution` | 五数要約2,4,6,9,12分の箱ひげ図 | 四分位範囲5分／範囲10分 |
| 中3 `quadratic-functions` | x=-3〜3の整数／y=9,4,1,0,1,4,9 | x=-2のyは4／x=1〜3の変化の割合4 |

折れ線は観測点間を線分で結び、放物線は二次曲線で描く。関数の座標軸は原点Oを通る。度数分布は同じ階級幅を隣り合う柱で表し、箱ひげ図は五数要約を同じ目盛りに置く。

## 検証手順

- Verify: `dotnet run --project tests/KidsTraining.ArchitectureTests/KidsTraining.ArchitectureTests.csproj -c Release --no-restore -- .`
- Expect: 実際に生成された14問の図表データから、差・合計・割合・変化の割合を独立計算した値と正答が一致する。Reactで生成されるデータ表にも同じ数値が出る。
- Verify: 生成済みアプリをChromeで1100pxと390pxの領域に表示し、図表・選択肢を確認する。データ表の開閉を操作する。
- Expect: 軸、単位、目盛り、凡例が読み取れる。図表や選択肢に横方向のはみ出しがない。行・列見出しと値が対応し、表からも同じ問題を解ける。

実画面での確認により、390pxでは図表を持つ問題の左右余白と問題文字サイズを調整し、SVG目盛りを拡大した。図の色だけに依存しないよう、円・帯には番号と凡例も示す。
