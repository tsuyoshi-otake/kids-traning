# 珠を動かすそろばん教材（#79）

小3のそろばんを、数を読む・数を置く・珠を動かして加減算する15問に変更した。実物で確認する活動カードも残す。

| 段階 | 内容 | 回答方法 |
|---|---|---|
| 1 | 0〜4を読む | 読み取り専用盤面を見て数字を入力 |
| 2 | 5・7・9を読む | 五珠と一珠を合わせて数字を入力 |
| 3 | 10・23・50を置く | 初期値0から珠を動かし盤面を確定 |
| 4 | 6+3／12−4 | 6→9、12→18→8の盤面を確定 |
| 5 | 7+8／23−7 | 7→17→15、23→26→16の盤面を確定 |

盤面は百・十・一の3桁。1桁につき五珠1個と一珠4個で、はりによせた珠だけを数える。一の位のはりには定位点を示す。珠の色に加え、位置と読み上げでも状態を確認できる。

一珠をよせる操作は、その珠からはり側の珠も一緒によせる。離す操作は、その珠より外側の珠も離す。したがって有効な盤面は常に各桁0〜9になる。クリックのほか、Tabで珠を選びEnterまたはSpaceで操作できる。

加減算では画面に示した補数の手順を練習する。12−4なら「6をたす」「10をひく」を順に確認し、途中の18だけでは得点を確定しない。動かさずに確定しても得点は付かない。「最初の盤面に戻す」は誤答回数を残す。誤答3回・最終正解・答えの表示は共通の採点処理で完了し、完了済みの操作を再採点しない。

## 検証

- Verify: `dotnet run --project tests/KidsTraining.ArchitectureTests/KidsTraining.ArchitectureTests.csproj -c Release --no-restore -- .`
- Expect: 0、5、7、10、23等の数値と15珠の状態が一致する。全15問の最終値が独立計算と一致する。6+3と12−4が途中・最終の各状態を通り、二重採点せず、誤答3回で終了する。
- Verify: 12−4の18を確定したところで保存し再開する。
- Expect: 盤面18・手順2・誤答回数を保持し、無効な桁値や手順番号の保存データを拒否する。
- Verify: Chromeで390pxの画面から6+3をクリック操作し、1100pxの画面から12−4をTab・Space・Enterで操作する。
- Expect: 最終値9、8で正解となる。途中の18を確定した後も珠が有効で、次の操作を続けられる。

実画面の検証で、描画後のコールバックだけで非同期ガードを解除すると、DOM上の珠が無効のまま残ることを確認した。途中処理は同期で完了するため、ガードを解除してから次の状態を描画する。回帰テストもコールバックより前の描画状態を検査する。
