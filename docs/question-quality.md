# 小学2年生の出題と全学年のふりがな（#81）

## 変更の目的と担当箇所

2年生の漢字・読解が初期段階で1年生の問題を選んでいたことと、単漢字の読みを連結して熟語の誤読を作っていたことを修正した。問題生成は既存の各 `*QuestionPatch.cs`、読み対象の指定は `CurriculumQuestion.ReadingTarget`、表示と読み辞書は `QuestionFuriganaPatch.cs` / `FuriganaVocabularyPatch.cs` が担当する。

学習履歴・進級・保存形式の所有者は変更しない。`ReadingTarget` は省略可能で、教材カタログから問題オブジェクトへ渡す表示上の契約。対象語は問題文内の全出現でルビを抑制し、解説では読みを表示する。通常の漢字問題は既存の対象語専用表示を使う。Markdownの問題文・選択肢にも同じ抑制規則を適用する。

## 2年生の出題範囲

- 漢字：全段階で2年生の対象語から出題する。誤答候補も既習学年内。1年生中心の絵問題を選ぶ早期分岐は2年生には適用しない。
- 読解：段階1＝本文の情報、2＝順序、3＝理由、4＝指示語、5＝気持ち・要点。各段階に3本文を用意し、正答の根拠を解説に示す。時計・日付の計算を読解の代わりに問わない。
- 分数：図の等分を伴う `1/2`、`1/3`、`1/4`、`1/8`。段階1〜3で図と表記、4で等分の意味、5で元の全体に戻す枚数を問う。分数計算・抽象的な大小比較は扱わない。[小学校学習指導要領解説・算数編](https://www.mext.go.jp/component/a_menu/education/micro_detail/__icsFiles/afieldfile/2019/03/18/1387017_004.pdf) の具体物を使った簡単な分数の指導を参照。
- 図形・乗法：正方形は等辺と直角の両方を説明する。かけ算の交換法則では、すべての選択肢を数値評価して正しいものが1つであることを検査する。

## ふりがなの契約

1. 語彙の最長一致を優先する。表示辞書は一度だけトライ木に構築する。漢字教材から再利用できるのは語全体の読みだけで、単漢字の音読み・訓読み・語幹を文章へ転用しない。
2. 数＋助数詞は全体で読む。人・時刻・年月日・分・本などの音変化、送り仮名や前後の文脈を反映する。
3. 未登録の熟語を単漢字の読みで埋めない。不明な部分は本文を保持する。辞書方式であり、日本語の任意の新文・同形異音語を完全に解析するものではない。
4. 表示変換は採点用文字列を変更しない。配列やReact要素を再変換して二重のルビを作らない。
5. 読みを問う対象語と漢字選択肢に答えのルビを付けない。新しい読み問題にも `ReadingTarget` を指定する。

## 2026-09-22 6年生の読みの再確認

ユーザーが指摘したのは問題内容ではなく、ふりがなの読み。前項の検査が成功した状態でも、次の不具合が残っていた。

| 箇所 | 修正前 | 修正後 |
| --- | --- | --- |
| 理科の問題文・解説の「リトマス紙」 | リトマスかみ | リトマスし |
| 漢字の解説で、出題と異なる読みを付ける | 机＝つくえ、骨＝ほね、私＝わたし、縦＝たて、窓＝まど、値＝あたい、背＝せ | その問題で教える読み：き、こつ、し、じゅう、そう、ち、はい |

## 2026-09-22 文脈と辞書の優先順位の追加修正

「もっとある」という指摘を受け、語ごとの最初の3例だけではなく、収集した全文章から文脈をたどれるようにした。問題・解説の実例で、さらに次の5種類の誤読を再現した。
