# 学年別の表示問題点検（Issue #83）

固定問題は計1,145問、変動問題の異なる抽出例は3,228件、初回判定は162問、漢字は1,026字、ドリルは600問。小学1〜6年の固定問題に含まれる推理720問は、表示される手掛かりから独立した解法で正答を照合した。漢字1,026字の代表読みは[文化庁の常用漢字表音訓索引](https://www.bunka.go.jp/kokugo_nihongo/sisaku/joho/joho/kijun/naikaku/kanji/joyokanjisakuin/)と照合した。「感じる」は音読み「カン」に送り仮名を付ける例として別に扱う。学年別の漢字数は[文部科学省の小学校学習指導要領](https://www.mext.go.jp/content/20230120-mxt_kyoiku02-100002604_01.pdf)に照らした。

今回直した表示内容は次のとおり。

1. 小1〜小3の助数詞問題は「くつを1数える」から「くつを数えるとき『1足』」に改め、問いの対象を明示した。読みを問う対象は、解答前に読み仮名が出ないよう保護した。
2. 小1〜小3の気持ちの解説にあった「〜から」のでを直し、「たのしみな気もち」とした。
3. 小1の三角形を組み合わせる問題から正答の四角形の図を外し、小2の正方形と小3の正三角形では、数学的に重なる選択肢を外した。
4. 小1の漢字ドリルでは初学者向けに不自然な単独読み「字→あざ」「千→ち」「天→あめ」を出さず、「文字」「千円」「天気」で練習できるようにした。小2は「語る」「図る」「自ら」の表記を正した。
5. 小4の「茨」「潟」「梨」の読みを正し、小6の手回し発電機の問題文が電気の変換を明確に問うようにした。

検証基準と実行方法：

- Verify: `dotnet run --project tests/KidsTraining.ArchitectureTests/KidsTraining.ArchitectureTests.csproj -c Release --no-restore -- .`。Expect: 29件成功、生成問題・推理・ふりがな・表示の監査に失敗がない。
- Verify: `node tests/KidsTraining.ArchitectureTests/DisplayedQuestionInventory.mjs <生成済み学習画面HTML> <出力先> 10`。Expect: `summary.json` の `generatorErrorCount` が0、全学年で `catalogQuestionCount === authoredQuestionCount`、初回判定が18問、6コースのドリルが各100問。
- Verify: 生成された `grade-1.json`〜`grade-9.json` の正答・選択肢・解説を学年順に調べる。Expect: 正答は一意、空欄・不正な文言・表示漏れがない。数式表示では分数線や上付き文字を文字列連結に還元せず、意味を持つ表示ノードとして扱う。
- Verify: 文化庁の音訓索引と小学1〜6年の漢字1,026件を照合する。Expect: 未掲載・不一致0件。索引上の音読みと送り仮名からできる「感じる」は別途説明を残す。

問題生成、読み仮名表示、固定教材バンクがそれぞれ状態・規則の所有者で、収集器は公開済みの生成ランタイム API だけを読む。次の同種の問題点検では学年別JSONから入れるため、無関係な画面実装や全教材定義を先に読む必要がない。一方、乱数問題の新しい型を追加するときは抽出範囲と独立した正答検証を見直す必要がある。
